# Voting_System
Voting Management System built with C++. Features include candidate registration, vote casting, result tracking, winner declaration, and file handling for saving election results.

Add candidates
Cast votes
View live vote results
Declare the winner
Save election results to a text file

# Features
Candidate management using structures
Voting system with input validation
Winner detection
File handling using fstream
Menu-driven console interface
Prevents invalid menu inputs

# Technologies Used
C++
File Handling (fstream)
Structures
Functions
Arrays
